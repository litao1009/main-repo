# novel_cover_pure_go · API 文档

纯 Go 版小说封面渲染器，根据封面图风格自动选择字体/配色/排版，叠加标题和作者文字。

---

## 快速开始

```bash
go build -o novelcover_pure .
./novelcover_pure \
    -image  cover.png \
    -name   "三体" \
    -writer "刘慈欣" \
    -out    output/santi.png \
    -fonts  ./fonts
```

## 主接口

```go
func RenderNovelCover(
    imagePath   string,   // 输入图片路径（支持 PNG/JPEG）
    nvlName     string,   // 小说名（中文）
    nvlWriter   string,   // 作者名（中文或英文）
    outPath     string,   // 输出路径（必须以 .png 结尾）
    titleRatio  float64,  // 标题区域占画幅高度比（默认 0.15）
    writerRatio float64,  // 作者区域占画幅高度比（默认 0.05）
    fontsDir    string,   // 字体文件目录
) error
```

### 命令行参数

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `-image` | 是 | - | 输入封面图路径 |
| `-name` | 是 | - | 小说标题 |
| `-writer` | 是 | - | 作者名 |
| `-out` | 否 | `out.png` | 输出 PNG 路径 |
| `-title-ratio` | 否 | `0.15` | 标题区高度比例 |
| `-writer-ratio` | 否 | `0.05` | 作者区高度比例 |
| `-fonts` | 否 | `fonts` | 字体目录 |

## 排版模式

### 自动决策规则

根据标题长度和画幅空间自动选择横排/竖排：

| 条件 | 排版 | 位置 |
|------|------|------|
| 标题 ≤ 8 字 且 最小字号 ≥ 22pt | **横排** | 下方 22% 区域 |
| 标题 > 8 字 或 字号过小 | **竖排** | 右方 20% 区域 |

```
横排 ─────────────────            竖排 ─────────────────
  ┌──────────────────┐              ┌──────────────────┐
  │                  │              │                  │
  │    封面图片      │              │    封面图片      │
  │                  │              │              │标 │
  │                  │              │              │题 │
  │   ┌─────────┐    │              │              │  │
  │   │  标题   │    │  ← 下22%     │              │竖│
  │   │  作者   │    │              │              │排│
  │   └─────────┘    │              │              │  │
  └──────────────────┘              │              │作 │
                                    │              │者 │
                                    └──────────────┴──┘
                                                   ↑ 右20%
```

### 手动指定排版

```go
// 强制竖排（长标题场景）
RenderNovelCover("cover.png", "钢铁是怎样炼成的", 
    "尼古拉·奥斯特洛夫斯基", "out.png", 0.15, 0.05, "fonts")
// → 自动检测到 9 字符，切换竖排（右 20% 区域）
```

## 文字渲染层次

每段文字由 4 层叠加：

```
┌──────────────────────┐
│  1. 外发光层          │  ← 粗描边 + 高斯模糊 (Box Blur ×2)
│  ┌────────────────┐   │
│  │ 2. 阴影层       │   │  ← 偏移 + 高斯模糊
│  │ ┌──────────┐   │   │
│  │ │ 3. 描边层  │   │   │  ← 圆圈采样描边
│  │ │ ┌──────┐ │   │   │
│  │ │ │4.主体层│ │   │   │  ← 纵向渐变填充 (Alpha mask)
│  │ │ └──────┘ │   │   │
│  │ └──────────┘   │   │
│  └────────────────┘   │
└──────────────────────┘
```

## 风格分析与配色

### 分析维度

| 维度 | 方法 | 用途 |
|------|------|------|
| 平均亮度 | HSV-V 全区采样 | 判定深色/浅色背景 |
| 平均饱和度 | HSV-S 全区采样 | 色彩丰富度 |
| 主色调 | 16-bin 色阶量化聚类 | 暖色/冷色判定 |
| 对比度 | 主色极差 | 高对比幕布判定 |

### 配色方案表

| 风格 | 条件 | fill（主色） | stroke（描边） | glow（发光） |
|------|------|-------------|---------------|-------------|
| 古风古典 | 暖 + 高饱和 + 红/橙 | `#FFD778` 金 | `#3C190A` 深棕 | `#FFB43C` 橙光 |
| 玄幻暗夜 | 暗 + 冷 | `#E6F0FF` 冰白 | `#0F1432` 深蓝 | `#78B4FF` 蓝光 |
| 安全白字 | 亮 + 高饱和 | `#FFFFFF` 白 | `#141414` 黑 | `#000000` 黑 |
| 温暖文艺 | 亮 + 暖 + 低饱和 | `#3C190F` 深棕 | `#FFF0DC` 米白 | `#B46432` 棕橙 |
| 清冷现代 | 亮 + 冷 + 低饱和 | `#191E3C` 深蓝 | `#F0F5FF` 冷白 | `#506EB4` 蓝光 |

## 字体

### 内置字体

| 文件 | 格式 | 适用 |
|------|------|------|
| `WenQuanYi-Micro-Hei.ttf` | TrueType | 通用 CJK |
| `WenQuanYi-Micro-Hei-Mono.ttf` | TrueType | 等宽 CJK |

### 字体自动选择

```
IsWarm && Saturation > 80 && (H < 50 || H > 330)  →  classical
IsDark && !IsWarm                                  →  bold
IsHighContrast && !IsDark                          →  high_contrast
Saturation < 60 && V > 160                         →  soft
default                                            →  modern
```

## 限制与扩展

| 场景 | 说明 |
|------|------|
| 输出格式 | 当前仅支持 PNG |
| 长标题 | 自动切换竖排（右 20% 区域），单行纵向布局 |
| 字体扩展 | 将 .ttf 放入 `fonts/` 目录即可，代码自动发现 |
| 配色定制 | 修改 `pickColor()` 函数中的规则表 |
| 超长作者名 | 竖排模式下自动使用稍小字号 |
